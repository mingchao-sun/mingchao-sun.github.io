市場の失敗(1)：売り手独占の理論

「価格を決める権利」を持つプライスメーカーの意思決定と、社会に生まれる損失（死荷重）を解き明かします。

東海大学政治経済学部経済学科　担当教員：孫明超

受

完全競争市場 (復習)

プライステーカー (価格受容者)

市場に多数の売り手と買い手がいるため、企業は市場価格 p を「自分で変えられないもの」としてそのまま受け入れます。 そのため、もう1単位追加で売った時の追加の収入（限界収入 MR）は、常に価格そのもの（MR = p）になります。

作

独占市場 (今回のテーマ)

プライスメーカー (価格決定者)

市場の供給者が1社しかいないため、企業が「生産量 x」を増やすと、市場の需要曲線に従って「価格 p」が下がってしまいます。 たくさん売るには価格を下げなければならないため、限界収入（MR）は価格より常に低くなります（MR < p）。

💡 Q1

なぜ限界収入(MR)は、需要曲線より傾きが急なの？

独占企業が「もう1個多く売る」ためには、「新しく増えた1個」の価格を下げるだけでなく、「今までに売れていた分」の価格もすべて下げなければならないからです。 そのため、新しく売って入るお金から、既存の製品を値下げした損失分が引かれるため、限界収入は需要曲線よりもはるかに早く減少します。

逆需要: p = 60 - 2x
限界収入: MR = 60 - 4x (傾きが2倍！)
⚖️ Q2

なぜ MR = MC のとき、利潤が最大になるの？

生産量を増やすかどうかは、「追加でもらえる収入（MR）」と「追加でかかるコスト（MC）」の天秤で決まります。
・MR > MC のとき：作れば作るほど儲かるので、もっと生産すべき。
・MR < MC のとき：作るほど赤字になるので、生産を減らすべき。
この２つの境目である「MR = MC」のとき、利潤は最高潮（極大）に達します。

📉 Q3

「死荷重(デッドウェイトロス)」ってなに？

独占企業は自分の利益を最大にするため、完全競争市場よりも「あえて生産量を少なくして、価格を高く」維持します。 これにより、「その値段なら買いたかった消費者」と「そのコストなら売りたかった企業」の取引チャンスが消滅します。 この社会的に失われた取引の利益（余剰の合計）を死荷重と呼び、独占が「市場の失敗」とされる最大の理由です。

PDF講義資料と整合したシミュレーション設定

1. 独占企業の意思決定パス

本シミュレーターでは、独占企業の行動メカニズムを以下のように完全再現しています。
① 限界収入と限界費用が一致する交点を求める (MR = MC) → 生産量 x* = 8 を決定。
② その生産量における消費者の許容価格を需要曲線から逆算する → 独占価格 p* = 44 に決定。
※これにより、価格受容者（プライステーカー）ではなく、価格設定者（プライスメーカー）としての動きを体感できます。

2. 社会的損失の発生

本来、完全競争市場であれば「限界費用（供給曲線）と需要曲線」が交わる点（生産量 x = 12、価格 p = 36）で取引され、社会的余剰は最大化します。
しかし、独占市場では生産量が 8 に制限されるため、グラフ上の三角形ABCの領域（死荷重 = 32万円分）が誰にも行き渡らず、煙のように消え去ってしまいます。

まとめ

独占企業は「MR = MC」で過少生産を選び、社会に死荷重を生む

独占企業はプライスメーカーとして、生産量を増やせば需要曲線に沿って価格が下がることを見越して行動します。 そのため限界収入は価格より常に低く（MR < p）、利潤が最大になる MR = MC の点では、 完全競争（x = 12、p = 36）よりも生産量をあえて絞り（x* = 8）、価格を高く（p* = 44）設定します。 この過少生産によって、本来なら成立したはずの取引が失われ、社会的余剰の一部が死荷重（32万円分）として誰の手にも渡らずに消えてしまいます。 これこそが、独占が「市場の失敗」とされる最大の理由です。
